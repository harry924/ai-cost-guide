Subscriptions vs paying per token

A $200 plan can cover thousands of dollars of usage at API prices. This page explains what Claude and ChatGPT/Codex plans actually give you, what each tier is worth, why they're priced the way they are, and what changed in autumn 2026. It includes the key points from two of Theo's (t3.gg) videos on the subject.

Researched 20 October 2026. Providers change limits often and publish few numbers, so the dollar values here are third-party measurements and estimates, not promises. New to token pricing? Start with API pricing.

What a subscription buys

A subscription doesn't give you a dollar budget. It gives you an allowance: a share of the provider's capacity that refills on a schedule. The provider decides how much of it each request uses, based on the model, the number of tokens and the speed setting.

To compare plans, people price the usage a plan allows at API rates. That's its API-equivalent value: what the same tokens would have cost if you'd paid per token. A plan that lets you use $7,000 of tokens a month for $200 is worth 35× its price in those terms.

It's a useful yardstick with two big weaknesses:

  • API prices aren't the provider's cost. They include a large margin, so the provider spends far less than the "value" figure to serve you. See why plans are so cheap.
  • Dollars don't measure work. A cheaper model can finish the same task for a small fraction of the cost, so a plan worth fewer API dollars can still get more done. See value per task.

How the limits work

  • Two clocks. Most plans have a rolling 5-hour window plus a weekly limit. Claude uses both on every paid plan. ChatGPT Plus has both. ChatGPT Pro currently has no 5-hour window, just a weekly limit.
  • Bigger models use it up faster. In Codex, GPT-6 Astra costs 5× as much allowance per token as GPT-6.1 Sol. On Claude Max, Fable models can use at most half of the weekly limit.
  • Speed costs extra. In Codex, Fast mode uses included usage at 2.5× the normal rate and Ultrafast at 8×.
  • Where you can use it. A Claude subscription works in Anthropic's own apps: Claude, Claude Code and Cowork. Since early 2026, third-party agent tools such as OpenClaw can't sign in with a subscription and need an API key or paid extra usage. Apps that run Claude Code itself, like T3 Code, still use the subscription. A Codex subscription can be used much more widely, according to Theo, as long as you don't use it to serve your own customers.
  • Going past the limit. Both providers let you keep working by paying: Claude through extra usage and usage credits, ChatGPT through credits.
  • Claude Max's API credits. Max 5x and Max 20x now include $100 and $200 a month of Claude API credit. It covers the API, Console, Managed Agents and the Agent SDK with an API key. It does not cover interactive Claude Code, and unused credit expires each month.

What stands out:

  • Claude plans cover about 35–40× their price at Anthropic's API prices, and the ratio is similar for Pro and Max 20x.
  • ChatGPT plans now cover about 13–15× their price when measured in GPT-6 Astra, and since 29 September the three Pro tiers give the same value per dollar. Before the change, the $200 plan gave Theo about 60×.
  • Model mix moves the numbers. Plus measured about $253 a month on real, mostly Sol-class traffic, but about $162 on Astra alone. A Claude Max 20x account running only Opus 5.5 measured about $11,700 a month.
  • Max 5x and the new Pro $100 and $200 tiers haven't been measured publicly yet.

Theo's numbers show how big the difference gets:

  • On his own Terminal-Bench runs, GPT-6.1 Sol at extra-high effort roughly tied Claude Opus 5.5, at $0.96 per task versus $13.11, about 13× cheaper.
  • In one week, about 1,800 GPT-6 Astra responses cost $534 at API prices, while about 1,500 GPT-6.1 Sol responses with a similar amount of output cost $38.27.

So a Codex plan worth half as many API dollars as before can still finish several times more tasks, if you use Sol instead of Astra. At those per-task costs, $1,000 of allowance covers about 76 Opus 5.5 tasks or about 1,040 Sol tasks. It's one benchmark, so treat the exact ratio as illustrative.

Two things the calculator can't show:

  • Where the usage happens. A Claude subscription only covers Anthropic's apps. Usage in other tools, scripts or your own product needs API billing anyway.
  • How evenly you work. Limits reset every 5 hours and every week. Heavy bursts can hit a limit even when your monthly total looks safely covered.

Why plans are so cheap, and why that's changing

Theo's explanation, from his first video:

  • API prices are mostly margin. He estimates providers have historically kept around 95% of API revenue over the cost of hardware and energy. On that estimate, serving $100 of tokens costs something like $2–5. In his words, both the subscription number and the API number are "fake."
  • The $200 plans are marketing. They were introduced to feel unlimited, back when people sent a handful of prompts a day. As models grew more capable and expensive, neither company wanted its top plan to suddenly feel limited, so the subsidy kept growing. The real money comes from cheaper consumer plans and API sales.
  • Competition is squeezing the margin. Anthropic released Fable 5 at $10/$50 per million tokens. Theo says the same model had been planned at $25/$125 as Mythos Preview, and estimates its margin fell from about 95% to 87.5%, which more than halves the profit per token. OpenAI matched Fable's price with GPT-6 Astra. It then priced GPT-6.1 Sol at $2/$10 with $0.10 cache reads, where Theo guesses margins may be closer to 50%.
  • So subsidies shrink. Thinner margins leave less room to give usage away. Theo reads Claude's half-limit for Fable and OpenAI's cut to the $200 plan as the start of that. His prediction: plans will cover fewer API dollars over time, but you'll still get more work done on the same plan a year from now, because the models keep getting cheaper and better.

The margins and planned prices are Theo's estimates, not figures published by Anthropic or OpenAI.

Theo: "I thought AI was gonna get cheaper?"

Watch on YouTube · 12 October 2026 · 18 minutes.

The question: Sam Altman promised intelligence would get about 10× cheaper every year, yet bills keep climbing. Theo spent around $800–1,000 on AI in all of 2025, and in 2026 he can spend $1,000 in a single day. His answer is that AI did get much cheaper; we're measuring it wrong.

  • 3:50 Top-end token prices did rise. GPT-5 cost $1.25 in and $10 out per million tokens. GPT-6 Astra costs $10 in and $50 out.
  • 4:35 But price per token is the wrong measure. He uses four: price per token, tokens needed per task, cost to reach a given level of intelligence, and what kinds of work the model can do. Cheap, capable models have also arrived at the bottom end, such as GLM 5.3 Flash at $0.15 in and $0.50 out.
  • 5:22 Token efficiency matters. A model that's cheap per token but wordy can lose most of its advantage per task. On the Artificial Analysis index, a Gemini Flash model's 10× price advantage over Astra shrank to under 3× per task, and Sonnet 5 cost more per task than Astra.
  • 6:54 The workload decides which price matters. Reading 800k tokens to categorize them is all input cost. Agentic coding depends on caching, reliability and token efficiency.
  • 7:40 The top costs the most. On the cost-versus-intelligence chart, a few extra points of score can triple the cost per task.
  • 8:25 Fixed capability gets much cheaper. DeepSeek V4 Flash scores about the same as GPT-5 Codex High at about 21× cheaper input and 55× cheaper output. Even assuming it needs 3× more tokens, that's roughly 20× cheaper in a year.
  • 9:13 Every level follows the same curve. Artificial Analysis data shows each new level of capability starting expensive and dropping to cents within months. One level fell from about $15 per task in September 2024 to about $0.16 by February 2025.
  • 13:06 Bills rise because use rises. Models now take a screenshot of a bug and land the fix, running for hours instead of seconds. Cheaper, better models get used for much more. That's the Jevons paradox: when coal got cheaper, total coal spending went up.

His conclusion: the promised 10× yearly drop happened, and then some, at any fixed level of capability. People spend more because the models can now do far bigger jobs.

Choosing a plan

  1. Estimate your usage at API prices first. If it's under the plan price, pay as you go. If it's above, a subscription is almost always cheaper.
  2. Check where you'll use it. If you rely on third-party agent tools, a Claude subscription won't cover them, but API billing or a Codex subscription can.
  3. Pick the model before the plan. The same allowance does very different amounts of work on Opus 5.5, Fable, Astra or Sol.
  4. Avoid speed modes on a subscription unless the speed is worth it. Fast uses the allowance 2.5× as fast and Ultrafast 8×.
  5. Don't assume the multiplier applies to the whole week. A "20×" Claude plan measured about 10× Pro per week.
  6. Expect the subsidy to shrink. Both companies are already trimming. Judge a plan by tasks finished per month, not by API dollars covered.
